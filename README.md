# Vendschat unsubscribe success

Static page for people who just left the mailing list.

## Deploy

1. `cd` this folder
2. Import it as a new Vercel project (static / other)
3. Attach a domain (example: `unsubscribed.vendschat.com`)
4. Set `UNSUBSCRIBE_SUCCESS_URL` on the CRM Vercel project to that https origin
